| P11 | Lost JOIN_CONFIRM (node image patched in a worktree to skip the transmit) | PASS | node: SAS 634244, 6 commit uplinks unacknowledged, `did not confirm (no ACK), key discarded, the previous pairing stays`; gateway committed nothing, window stayed open; the unpatched image then paired in the same window (SAS 041795) |
| P12 | Full registry (14 fake `node_add` + A + B = 16) | PASS | 15th `node_add` refused `capacity exhausted`; `nodes add --ota` refused the same way; the 16-entry listing streams complete; CLI said "window open" before the refusal (reworded) |

By design (documented): while a pairing window is open the gateway hears only pairing frames, so
a registered node's uplink in that time goes unacknowledged; an exported `rx_floor` can lag the
node's real counter by up to P = 32 after a gateway reboot.
